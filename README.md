# Restaurant Management System

A desktop application developed using C# Windows Forms and Microsoft SQL Server.

## Technologies
- C#
- Windows Forms
- .NET Framework 4.5
- Microsoft SQL Server
- DataSet

## Setup and Configuration

1. Install Microsoft SQL Server.
2. Create or restore the `Restoran` database.
3. Open `App.config` in the project.
4. Replace the `Data Source` value with your local SQL Server instance name.
5. Ensure that Windows Authentication is enabled and your Windows account has access to the database.
6. Open `rest.sln` in Visual Studio and build the project.

## Database Requirements

The application requires a database named `Restoran`. The database structure must match the tables and queries used by the application.
